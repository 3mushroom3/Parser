📥 Импорт из XLS/XLSX

Загрузите файл с производителями — колонки (название, ИНН, телефон, адрес, руководитель, культуры, площадь) определяются автоматически по шапке и содержимому, в любом порядке. Если производитель уже есть в ФСА-базе — только обновится карточка компании. Если нет — создастся новая запись для поиска.

Сокращение организационных форм

Заменяет полные наименования на аббревиатуры: «Общество с ограниченной ответственностью» → ООО, «Акционерное общество» → АО и т.д.

Архивация старых деклараций

ФСА не понижает статус декларации, даже если ей много лет — переводим в статус "В архиве" декларации старше года, которые ФСА всё ещё помечает как "действует". Происходит автоматически после каждого прогона парсера; кнопка — для разового прохода по уже накопленным данным.

Чекпоинт парсера

Парсер запоминает, до какой даты дошёл, и не пересканирует пройденные окна при перезапуске/деплое. Нажмите, если нужно заново пройти всю историю с FSA_DATE_FROM (например, чтобы перепроверить статусы старых деклараций).

🔑 FSA токен (ручная установка)

Если парсер перестал работать из-за ошибки авторизации — вставьте JWT-токен вручную. Получить: открыть pub.fsa.gov.ru в браузере → F12 → Application → Local Storage → найти accessToken.

Дубли производителей

Проставляет ИНН декларациям без него, если для того же названия+адреса в базе уже есть ровно один известный ИНН — устраняет "размножение" одной компании на несколько карточек.

Спорные дубли

Одно название+адрес — несколько разных ИНН. Открывается в отдельном окне.

📄 Пользовательское соглашение

1. Общие положения

Настоящее соглашение регулирует условия использования информационно-аналитического сервиса «KOVELIA — Агро реестр» (далее — Сервис). Используя Сервис, вы принимаете условия настоящего соглашения в полном объёме.

2. Источник данных

Все сведения о декларациях соответствия, представленные в Сервисе, получены исключительно из открытого государственного реестра Федеральной службы по аккредитации (Росаккредитация) — официального портала pub.fsa.gov.ru, функционирующего в соответствии с Федеральным законом № 412-ФЗ «Об аккредитации в национальной системе аккредитации».

Указанные данные являются общедоступными и размещены государственным органом в открытом доступе для неограниченного круга лиц. Сервис не является официальным ресурсом Росаккредитации и не аффилирован с ним. Сервис выполняет функцию агрегатора и инструмента удобного поиска по открытым данным.

При этом результаты обработки данных Сервисом — классификация производителей (фермер/трейдер), объединение дублирующихся записей по ИНН, контактные данные, заметки, описания и иные сведения, добавленные администрацией Сервиса сверх первичных данных pub.fsa.gov.ru, — образуют самостоятельную базу данных. Исключительное право изготовителя базы данных (ст. 1334 ГК РФ) на неё принадлежит администрации Сервиса.

3. Актуальность данных

Данные периодически обновляются из источника pub.fsa.gov.ru. Сервис не несёт ответственности за расхождения между отображаемой информацией и актуальным состоянием реестра Росаккредитации. Для получения юридически значимых сведений следует обращаться непосредственно к официальному реестру.

4. Условия использования

Пользователь обязуется использовать Сервис только в законных целях и не предпринимать действий, направленных на автоматизированный доступ к данным Сервиса в обход штатного веб-интерфейса, в том числе:

— парсинг, скрейпинг, использование ботов, скриптов, краулеров и иных автоматизированных средств для массового извлечения данных;

— обход или попытки обхода технических средств защиты (ограничений частоты запросов, объёма выдачи, авторизации);

— использование нескольких учётных записей для обхода ограничений, установленных в отношении одной учётной записи;

— воспроизведение, систематическое извлечение существенной части базы данных Сервиса, а также её копирование, перепродажу, передачу третьим лицам или включение в собственные продукты и базы данных без предварительного письменного согласия администрации Сервиса.

При выявлении нарушения настоящего пункта администрация Сервиса вправе без предварительного уведомления заблокировать учётную запись Пользователя без возврата уплаченных денежных средств за неиспользованный период подписки, а также взыскать с Пользователя неустойку в размере 100 000 (ста тысяч) рублей за каждый зафиксированный факт нарушения (ст. 330 ГК РФ). Уплата неустойки не лишает администрацию Сервиса права требовать возмещения убытков, фактически причинённых таким нарушением, в части, не покрытой неустойкой (ст. 15, 393 ГК РФ).

5. Подписка и оплата

Доступ к расширенному функционалу Сервиса предоставляется на платной основе. Подписка активируется после успешного прохождения оплаты. Возврат средств за неиспользованный период подписки не предусмотрен.

6. Ограничение ответственности

Сервис предоставляется «как есть». Администрация не несёт ответственности за достоверность сведений, полученных из открытого реестра pub.fsa.gov.ru, а также за возможные перебои в работе Сервиса, вызванные техническими причинами или изменениями в работе источника данных.

7. Персональные данные

При регистрации сохраняется только логин и хеш пароля. Сервис не собирает и не передаёт персональные данные пользователей третьим лицам. Обработка персональных данных осуществляется в соответствии с Федеральным законом № 152-ФЗ «О персональных данных».

🔐 Политика конфиденциальности

1. Общие положения

Настоящая политика определяет порядок обработки персональных данных пользователей сервиса «KOVELIA» (далее — Сервис) администрацией Сервиса в соответствии с Федеральным законом № 152-ФЗ «О персональных данных».

2. Какие данные собираются

При регистрации: логин и пароль (хранится только в виде необратимого хеша, не в открытом виде). При оформлении подписки: сведения об оплате обрабатываются платёжным оператором ЮKassa; Сервис не получает и не хранит данные банковских карт. При обращении в поддержку: текст обращения и, при необходимости, приложенный скриншот.

Отдельно: если пользователь загружает через раздел «Мои базы» собственный файл с контактами компаний, эти сведения — данные о юридических лицах, а не персональные данные пользователя — хранятся в его личном разделе и не передаются другим пользователям Сервиса.

3. Цели обработки

Аутентификация пользователя, предоставление доступа к функциям Сервиса, отправка уведомлений (только при явном включении пользователем), обработка и учёт подписки, обработка обращений в поддержку.

4. Хранение и защита данных

Данные хранятся на сервере Сервиса. Пароли хранятся в хешированном виде (bcrypt), восстановлению в исходном виде не подлежат. Доступ к данным ограничен администрацией Сервиса.

5. Передача третьим лицам

Данные об оплате передаются платёжному оператору ЮKassa в объёме, необходимом для проведения платежа, в соответствии с его собственной политикой конфиденциальности. Иным третьим лицам персональные данные не передаются и не продаются.

6. Локальное хранилище браузера

Сервис использует localStorage браузера для хранения токена сессии и пользовательских настроек интерфейса. Эти данные хранятся только на устройстве пользователя и не передаются третьим лицам.

7. Права пользователя

Пользователь вправе в любой момент запросить удаление своего аккаунта и связанных с ним данных, а также уточнение или исправление данных, обратившись к администрации Сервиса.

8. Изменение политики

Администрация Сервиса вправе вносить изменения в настоящую политику. Актуальная редакция всегда доступна по ссылке в подвале сайта.
